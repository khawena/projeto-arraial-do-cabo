# 🌊 Arraial do Cabo: apresentação do projeto
Este projeto Front-end demonstra os avanços que obtive no desenvolvimento de interfaces visuais. Tomei como ponto de partida a ideia de criar um portal que apresentasse a cidade de Arraial do Cabo e as experiências que podem ser vivenciadas nela. Optei por um design que destacasse as belezas naturais. 
O projeto concentra-se nas experiências que Arraial do Cabo oferece aos visitantes. Por isso, informações sobre hospedagem, alimentação e passagens não fazem parte desta versão.

## 🗂️ Estrutura das páginas
O site conta, atualmente, com cinco páginas:  
Início  
A cidade  
Experiências  
Praias  
Planejador de viagem

## 💡 Processo de desenvolvimento 
Nas duas primeiras páginas utilizei Flexbox, enquanto nas duas seguintes utilizei CSS Grid. Acredito que cada página pedia uma abordagem diferente.  
A página inicial proporciona uma experiência mais contemplativa, valorizando a paisagem natural do destino e convidando o usuário a navegar entre as demais. Já a página A cidade possui uma proposta mais textual, reunindo informações que contextualizam Arraial do Cabo.  
Já nas duas páginas seguintes destaquei o que a cidade tem a oferecer, por isso a organização dos cards interativos a partir do CSS grid. A expansão do conteúdo foi implementada apenas com HTML e CSS, utilizando <input type="checkbox"> associado a <label>, dispensando o uso de JavaScript nesta etapa do projeto. Muito em breve, pretendo agregar mais dinamicidade a essas páginas fazendo uso do DOM.  
Sobre a quinta página: ela ainda está em construção e pede um formulário. Estou desenvolvendo um MVP via terminal em JavaScript, que futuramente servirá de base para integrar essa funcionalidade ao site.   
As cinco páginas compartilham a mesma identidade visual, construída a partir do uso de uma imagem de fundo da cidade de Arraial do Cabo, servindo como principal norte para a escolha de cores, fontes e espaçamentos. Além do menu navegável no topo.
